# Visible Librarian Trades — Minecraft 26.2 Fabric port

This is a client-side port of Saphjyr's original [Visible Librarian Trades](https://github.com/Saphjyr/visible-librarian-trades). It displays the nearby librarian's existing enchanted-book trade on the lectern, without changing trades, RNG, items, or lecterns.
